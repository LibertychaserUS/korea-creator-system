# 页面说明

## 当前版本
- `v8a-dashboard`
- 日期：2026-06-18

## 技术栈
- 后端：FastAPI
- 前端：原生 HTML / CSS / JavaScript
- 图表：ECharts

### 左侧导航
- 概览
- 达人库
- AI复核
- 人工复核
- 邮件触达
- 数据与导出
- 规则设置

### 顶部工具栏
- 当前国家/地区
- 当前平台
- 数据更新时间
- 全局搜索
- 中文 / EN / 한국어
- 当前项目名称

### 展示内容
- 达人总数
- Top50 数量
- 最终分平均值
- AI真实复核数量及覆盖率
- 人工待确认数量
- 规则与AI冲突数量
- 数据更新时间
- AI来源说明

### 图表
- Top10 最终分横向柱状图
- S / A / B / C / D 等级分布环形图
- 内容关键词 Top10
- 地区 / 国家分布
- 地图降级逻辑：
  - 尝试显示世界地区分布图
  - 若 GeoJSON 加载失败，自动退化为地区排行图

### 其他模块
- AI复核状态概览
- 最近人工复核记录
- 最近 AI 复核记录

## 达人库页

### 列表核心列
- 排名
- 昵称
- 平台
- 国家/地区
- 等级
- 最终分
- 粉丝数
- 报价
- 合作ER
- AI状态
- 人工状态

### 支持能力
- 视图切换：Top10 / Top50 / 全量
- 筛选：
  - 国家
  - 平台
  - 等级
  - AI状态
  - 人工状态
- 搜索：
  - 昵称
  - 关键词
- 分页
- 排序
- Excel / CSV 下载

### 详情交互
- 点击达人后从右侧打开详情抽屉。
- 不再使用长弹窗。

### 详情抽屉标签页
- 概览
- 评分依据
- AI复核
- 人工复核

### 评分依据内容
- 六维雷达图
- 六维分数条
- 实际权重
- 最终分计算结果
- 命中关键词
- 风险扣分原因

### AI复核内容
- AI来源：DeepSeek 真实调用 / success 缓存 / fallback 模板
- 决策：recommend / cautious / reject
- 核心原因
- 风险
- 合作建议
- 与规则评分是否冲突
- 明确提示：AI 不修改评分与排名

### 人工复核内容
- 保留现有按钮
- 保留备注输入
- 保留保存逻辑

## AI复核页

### 展示内容
- AI覆盖率
- success / fallback / 失败数量
- recommend / cautious / reject 分布
- 规则与 AI 冲突数量
- 待复核达人列表
- AI来源说明与更新时间
- 批量生成 AI复核按钮

### 交互
- 点击达人时复用同一个详情抽屉。
- 保留 `POST /api/ai/run` 与 `GET /api/ai/status` 行为不变。

## 多语言覆盖范围
- 已支持语言：
  - `zh-CN`
  - `en`
  - `ko`
- 已覆盖内容：
  - 公共导航
  - 按钮
  - 筛选器标签
  - 状态文案
  - 空状态
  - 错误提示
  - 页面标题与模块标题
- 保持原文不翻译：
  - 达人昵称
  - 原始关键词
  - 人工备注

### 语言切换规则
- 选择结果保存到 `localStorage`
- 页面刷新后保留上次选择
- 不调用外部翻译接口
