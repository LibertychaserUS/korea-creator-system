# 页面说明

四个 Nuxt 端都 extend `libs/panel`：同一套壳（侧栏、顶栏、语言 / 主题 / 同意条）、同一登录页、同一 composables（`useApi` `useSession` `useMetrics` `useFormat` `useTheme` `useConsent`）。路由带语言前缀 `/{zh-CN|en|ko}/…`。testid 的权威在 `packages/kcs-contract/src/testids.ts`；页面级 testid 是 `screen-<letter>-<name>`。

界面上的每个数字都来自 `CreatorMetrics`，展示统一走 `MetricValue`（按单位格式化 + 分位色带 + 悬停口径与"同源同量级 N 人"），量级用 `TierBadge`，健康等级用 `HealthBadge`，来源用 `SourceBadge`（fixture 时带"样例"）。

## 宣传站 marketing（7005）

单页 `apps/marketing/pages/index.vue`，公开。区块：

1. Hero：一句话 + 登录入口。
2. 数据来源：路线 A 蒲公英（官方 / TikHub / JustOneAPI）、路线 B 千瓜 / 新红；明确"不自建抓取，取不到的不编"。
3. 指标怎么读：六个指标组、量级、健康等级、分位（同源同量级）。
4. 筛选方案：替代评分；示例条件。
5. 四个端各做什么。
6. 预览表（静态，字段来自 `GET /api/metrics/fields`）。

文案见 11。

## 状态与色调

`StatusBadge` 统一翻译与配色：`ok` 绿、`running` 蓝、`queued` / `partial` 琥珀、`failed` 红；博主 `draft` / `review` / `ready` / `released` 同理。分位色带：`top10` 主色加粗、`top25` 主色、`upper` 正常、`lower` 弱化、`bottom` 琥珀；只在 top25 以上和 bottom 点亮小圆点。
