## 本轮接口变更结论

## 原有兼容接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/` | 主页面 |
| GET | `/api/summary` | 旧版评分摘要，保留兼容 |
| GET | `/api/creators` | 达人列表，支持视图、筛选、搜索、分页 |
| GET | `/api/creator/{rank}` | 达人详情 |

| POST | `/api/ai/run` | 触发 AI复核生成 |
| GET | `/api/ai/status` | AI缓存状态 |
| POST | `/api/manual/update` | 保存人工标注 |
| POST | `/api/manual/save` | 旧入口，返回兼容提示 |
| GET | `/api/manual/list` | 获取人工标注列表 |

## 新增接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/dashboard` | 概览页聚合数据与图表数据 |
| GET | `/api/filter-options` | 达人库筛选项字典 |
| GET | `/api/ai/reviews` | AI复核页列表与覆盖率统计 |

## GET /api/dashboard
- 用途：概览页展示核心指标、图表、AI状态概览、最近人工复核记录。
- 数据来源：
  - `data/output/scores_full.csv`
  - `data/cache/scoring_summary.json`
  - `data/cache/ai_recommendations.json`
  - `data/cache/manual_reviews.json`

响应示例：
```json
{
  "version": "v8a-dashboard",
  "total_creators": 1725,
  "top50_count": 50,
  "final_score_avg": 45.17,
  "ai_real_review_count": 10,
  "ai_total_review_count": 50,
  "pending_manual_count": 49,
  "conflict_count": 50,
  "charts": {
    "top10_scores": [],
    "grade_distribution": [],
    "keyword_top10": [],
    "region_distribution": [],
    "map_distribution": []
  },
  "ai_status_overview": {
    "success": 10,
    "fallback": 40,
    "failed": 0
  }
}
```

错误情况：
- 缺少核心数据文件时返回 500。
- 图表数据为空时仍返回结构化空数组，前端显示空状态。

## GET /api/filter-options
- 用途：为达人库筛选器提供国家、平台、等级、AI状态、人工状态等枚举值。

响应示例：
```json
{
  "countries": ["中国", "韩国", "日本"],
  "platforms": ["小红书"],
  "grades": ["A", "B", "C", "D"],
  "ai_statuses": ["success", "fallback", "missing"],
  "manual_statuses": ["recommend", "reject", "pending", "reviewed"]
}
```

## GET /api/ai/reviews
- 用途：AI复核页读取 Top50 AI记录、覆盖率和冲突统计。
- 查询参数：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|------|------|
| `page` | int | 1 | 页码 |
| `page_size` | int | 20 | 每页条数 |
| `decision` | str | 空 | 按 AI 决策筛选 |
| `status` | str | 空 | 按 AI 来源状态筛选 |
| `search` | str | 空 | 昵称关键字搜索 |

响应示例：
```json
{
  "records": [],
  "total": 50,
  "page": 1,
  "per_page": 20,
  "coverage": {
    "total_top50": 50,
    "reviewed": 50,
    "success": 10,
    "fallback": 40,
    "failed": 0,
    "conflict_count": 50
  }
}
```

## POST /api/ai/run
- 行为保持兼容。
- 用于批量生成 Top50 AI复核。

查询参数：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|------|------|
| `limit` | int | 50 | 处理条数，1-50 |

## GET /api/ai/status
- 行为保持兼容。
- 返回是否可用、总数、success 数、fallback 数。

## POST /api/manual/update
- 行为保持兼容。
- 请求体：
```json
{
  "rank": 1,
  "decision": "recommend",
  "note": "内容匹配，建议试投",
  "reviewer": "人工"
}
```

响应体：
```json
{
  "ok": true,
  "rank": "1",
  "review": {
    "rank": "1",
    "decision": "recommend",
    "note": "内容匹配，建议试投",
    "reviewer": "人工",
    "updated_at": "2026-06-18T22:25:17.440722"
  }
}
```

错误情况：
- 请求体缺少必要字段：400
- 缓存文件读写异常：500

## 2026-06-18 第八阶段 A.1 接口修正

### 保持兼容的接口
- `GET /api/creators`
- `GET /api/creator/{rank}`
- `GET /api/ai/reviews`
- `GET /api/ai/status`
- `POST /api/ai/run`
- `POST /api/manual/update`
- `GET /api/download/{file_type}`

### 1. GET /api/dashboard
- 本轮无路径变化，字段口径修正为“真实 success 决策统计”。
- 关键字段：
  - `ai_real_review_count`
  - `hard_conflict_count`
  - `soft_divergence_count`
  - `consistent_count`
  - `unknown_ai_count`
  - `ai_status_overview.success`
  - `ai_status_overview.fallback`
  - `ai_status_overview.pending`
  - `ai_status_overview.failed`
  - `ai_status_overview.decision_base_count`
  - `ai_status_overview.decision_distribution`
  - `ai_status_overview.alignment_distribution`
- 说明：
  - `decision_distribution` 只统计真实 `success`
  - `fallback` 不参与真实决策比例与强冲突率

### 2. GET /api/creators
- 新 UI 继续复用此接口。
- 本轮补充字段：
  - `creator_key`
  - `ai_alignment_level`
  - `ai_hard_conflict`
  - `ai_soft_divergence`
- 说明：
  - `ai_conflict` 现在表示“真实 success 且存在冲突或偏差”
  - 详情展示应优先使用 `ai_alignment_level`

### 3. GET /api/creator/{rank}
- 保持路径不变。
- 本轮补充/稳定用于详情抽屉的字段：
  - `weight_labels`
  - `score_dimensions`
  - `manual_review`
  - `ai_recommendation.alignment_level`

### 4. GET /api/ai/reviews
- 支持的 `view`：
  - `all`
  - `pending`
  - `success`
  - `fallback`
  - `hard_conflict`
  - `soft_divergence`
  - `consistent`
- 返回结构中的 `coverage` 已按新口径修正：
  - 真实 success 与 fallback 分开统计
  - 冲突分布只基于真实 success

### 5. GET /api/ai/status
- 保持兼容。
- 本轮新增：
  - `translation_api_key_available`

### 6. POST /api/ai/translate
- 新增接口。
- 用途：在不重跑主 AI 复核的前提下，为详情抽屉返回本地化自然语言说明。
- 请求体：
```json
{
  "rank": 1,
  "target_language": "en"
}
```
- 响应字段：
```json
{
  "rank": 1,
  "creator_key": "5bba31d1ef3da50001c87bc1",
  "language": "en",
  "translated": true,
  "used_original": false,
  "cache_status": "hit",
  "source_hash": "sha256...",
  "payload": {
    "summary": "string",
    "reasons": ["string"],
    "risks": ["string"],
    "collab_suggestions": ["string"],
    "review_hint": "string",
    "conflict_reason": "string"
  },
  "original": {
    "summary": "原文",
    "reasons": ["原文"]
  },
  "meta": {
    "decision": "cautious",
    "status": "success",
    "alignment_level": "soft_divergence"
  }
}
```
- 失败与兜底：
  - 无 API Key 或翻译失败：返回原文，`translated=false`
  - `fallback`：返回本地化模板，`cache_status=fallback_template`

### 7. 实测兼容性

- `GET /api/ai/reviews`：200
- `POST /api/ai/translate`：200
- `GET /favicon.ico`：200
- `/docs`：正常可打开

## 2026-06-19 第八阶段 A.2 接口修正

### 行为修正，接口保持兼容

### 1. GET /api/dashboard
- 新增字段：
  - `data_source_note_key`：数据说明翻译key
  - `ai_source_note_key`：AI说明翻译key
  - `data_source_note_vars`：数据说明变量
  - `ai_source_note_vars`：AI说明变量
- 说明：
  - 原硬编码中文 `data_source_note` 和 `ai_source_note` 改为返回结构化数据
  - 前端使用 `t(key, vars)` 函数进行本地化

### 2. GET /api/creator/{rank}
- 新增字段：
  - `rule_note_key`：规则说明翻译key
  - `score_dimensions[].label`：维度标签翻译key（如 `dimension.layered_match`）
  - `weight_labels`：权重标签翻译key
- 说明：
  - 原硬编码中文标签改为返回翻译key
  - 前端使用 `t()` 函数进行本地化

### 3. POST /api/ai/translate
- 行为保持兼容
- 缓存校验增强：
  - 缓存键包含 `source_hash`
  - 原文变化后旧翻译自动失效
