# 指标口径与数据源

系统不计算综合分、推荐等级或关键词权重。采集任务接收参数化查询，由数据源适配器拉取原始 JSON；原始响应原样保存在 `creator_raw`，转换层再写入统一的 `CreatorMetrics`。筛选、排序和高亮通过可保存的 `SavedQuery` 表达。

## 数据源与路线

| 数据源 | 路线 | 鉴权 | 主要能力 |
|---|---|---|---|
| 蒲公英 OpenAPI | A：小红书商业开放平台官方接口 | App ID、App Secret、Access Token | 博主报价、投前博主数据、投后数据、健康等级、粉丝画像、合作品牌 |
| 千瓜 | B：第三方数据供应商 | Bearer Token | 千瓜指数、爆文、近 30 天发文/涨粉、粉丝真实度、预估报价、CPE、CPM |
| 新红 | B：第三方数据供应商 | Bearer Token | 新红指数、传播中位数、近 30 天内容与涨粉、粉丝真实度、报价、CPE、CPM |

系统没有路线 C，也不进行自建抓取。未配置凭证时，后端只返回明确标记为 `fixture` 的样例数据，供本地开发和演示使用。

## 字段映射

真实供应商响应可能因购买套餐和 API 版本不同而变化。适配器把路径集中在各自的 `FIELD_MAP`，确认实际文档后只需调整路径表。

### 蒲公英

| 供应商字段 | 统一字段 |
|---|---|
| 粉丝数、涨粉 | `followers`, `followerGrowth` |
| 曝光中位数、阅读中位数、互动中位数 | `impressionMedian`, `readMedian`, `interactionMedian` |
| 点赞/收藏/评论中位数 | `likeMedian`, `collectMedian`, `commentMedian` |
| 互动率、阅读粉丝占比、活跃粉丝占比 | `engagementRate`, `readFanRatio`, `activeFanRatio` |
| 图文报价、视频报价、预估阅读成本、CPE | `priceImage`, `priceVideo`, `cpv`, `cpe` |
| 健康等级、合作品牌 | `health`, `coopBrands` |

### 千瓜

| 供应商字段 | 统一字段 |
|---|---|
| 粉丝数、涨粉、近 30 天发文、爆文数 | `followers`, `followerGrowth`, `noteCount`, `viralCount` |
| 阅读/互动/点赞/收藏/评论中位数 | 对应 `*Median` |
| 粉丝真实度 | `authenticity` |
| 预估报价、CPE、CPM | `priceImage`, `cpe`, `cpm` |
| 千瓜指数 | `vendorIndex: { name: "千瓜指数", max: 1000 }` |

### 新红

| 供应商字段 | 统一字段 |
|---|---|
| 粉丝数、近 30 天涨粉、近 30 天发文、爆文数 | `followers`, `followerGrowth`, `noteCount`, `viralCount` |
| 曝光/阅读/互动/点赞/收藏/评论中位数 | 对应 `*Median` |
| 粉丝真实度 | `authenticity` |
| 图文/视频报价、CPE、CPM | `priceImage`, `priceVideo`, `cpe`, `cpm` |
| 新红指数 | `vendorIndex: { name: "新红指数", max: 1000 }` |

无法从响应读取的数字必须保留 `null`，不得用默认值或推测值补齐。

## 派生比率

转换层只计算可由原始字段直接复算的比率；供应商已经提供该字段时保留供应商值。

| 指标 | 公式 |
|---|---|
| CPE | 图文报价（无则视频报价）÷ 合作互动中位数（无则互动中位数） |
| CPM | 报价 ÷ 合作阅读中位数（无则阅读中位数）× 1000 |
| 互动率 | 互动中位数 ÷ 阅读中位数 |
| 收藏赞比 | 收藏中位数 ÷ 点赞中位数 |
| 读粉比 | 阅读中位数 ÷ 粉丝数 |
| 涨粉率 | 涨粉 ÷（当前粉丝数－涨粉） |
| 爆文率 | 爆文数 ÷ 近 30 天发文数 |

分母为 0、缺失或非有限数时结果为 `null`。

## 粉丝层级

| 层级 | 粉丝数 |
|---|---|
| 头部 `head` | 大于等于 50 万 |
| 腰部 `mid` | 5 万（含）至 50 万 |
| 初级 `junior` | 5 千（含）至 5 万 |
| 素人 `amateur` | 300（含）至 5 千 |
| 未知 `unknown` | 缺失或低于 300 |

边界在代码中按下限包含处理，因此 50 万属于头部，5 万属于腰部，5 千属于初级，300 属于素人。

## 同层百分位

可比较指标只在相同粉丝层级中计算百分位。高值更好的指标直接排名；CPE、CPM 等低值更好的指标反向排名，因此百分位越高始终代表同层表现越靠前。

| 分带 | 百分位 |
|---|---|
| `top10` | ≥ 90 |
| `top25` | 75–89.9 |
| `upper` | 50–74.9 |
| `lower` | 25–49.9 |
| `bottom` | < 25 |

同层有效样本少于 2 个时不生成该指标的百分位。

## 健康等级硬门槛

蒲公英健康等级统一为 `excellent`、`normal`、`abnormal`。健康等级不是加权项，而是可直接阻断候选的硬筛选条件。业务查询可以只允许 `excellent`，也可以显式包含 `normal`；`abnormal` 不应因其他指标突出而被综合分“抵消”。

## 发布快照与审计

发布达人时，当前 `metrics` 原样复制到 `metrics_locked`。后续采集或运营更新可以改变当前指标，但不能修改已发布快照。每次适配器采集的供应商 JSON 都单独写入 `creator_raw`，用于追溯字段映射和供应商口径变化。
