# 演示流程

## 启动
```bash
uvicorn app.web:app --reload --port 5000
```

- 页面地址：`http://127.0.0.1:5000`
- API 文档：`http://127.0.0.1:5000/docs`

## 推荐演示顺序

### 1. 概览
- 打开首页，先展示左侧导航和顶部工具栏。
- 说明系统定位：全球达人情报系统。
- 重点说明所有统计与图表均来自真实项目数据，不使用设计稿示例数字。
- 展示关键指标：
  - 达人总数 1725
  - Top50 数量 50
  - 平均最终分 45.17
  - AI真实复核 10 条
  - 人工待确认 49 条

### 2. 达人库
- 切换到达人库页。
- 展示 Top10 / Top50 / 全量切换。
- 使用国家、等级、AI状态、人工状态筛选。
- 演示搜索与分页。

### 3. 评分依据
- 点击任意达人打开右侧详情抽屉。
- 切到“评分依据”标签页。
- 展示六维雷达图、分数条、命中关键词、风险扣分原因。
- 强调：
  - 规则评分负责排序。
  - 本轮未修改任何评分算法、权重、等级阈值。

### 4. AI复核
- 切到“AI复核”标签页或进入 AI复核独立页。
- 展示 success / fallback 区别。
- 展示 recommend / cautious / reject 的解释位。
- 强调：
  - AI 负责风险复核。
  - AI 不修改评分与排名。

### 5. 人工标注
- 在详情抽屉切到“人工复核”标签页。
- 演示推荐 / 不推荐 / 待确认 / 已复核按钮与备注输入。
- 说明人工拥有最终确认权。

### 6. 导出
- 回到达人库页，点击 Excel / CSV 下载。
- 说明导出仍兼容现有后端能力。

### 7. 多语言
- 在顶部切换中文 / EN / 한국어。
- 展示公共导航、按钮、状态切换。
- 说明达人昵称、原始关键词、人工备注保持原文，不做机器翻译。

## 演示核心话术
- 规则评分负责大规模排序。
- AI 负责 Top50 风险复核与合作建议。
- 人工负责最终确认。
- 三者形成可追踪、可解释、可导出的演示闭环。
