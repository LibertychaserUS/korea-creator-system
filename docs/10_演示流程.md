# 演示流程

用样例数据（fixture）走完整闭环：抓 → 转 → 筛 → 派 → 导出。约 10 分钟。启动步骤见 `HANDOFF.md`。

账号（密码 `Kcs!demo2026`）：`ops@kcs.local`（运营）、`selector@kcs.local`（选人）、`devops@kcs.local`（运维）、`admin@kcs.local`（全部）。

## 0. 宣传站（7005）— 1 分钟

打开 `/zh-CN/`。讲三件事：数据从哪来（路线 A / B，不自建抓取）、指标怎么读（六组、量级、健康、同源同量级分位）、筛选方案替代评分。切 `en` / `ko` 看三语，切深色。

## 1. 运营端 → 数据源（7002）— 3 分钟

1. 登录 `ops@kcs.local`，进「数据源」。
2. 三张适配器卡：蒲公英（路线 A，凭证 `PGY_ACCESS_TOKEN` + 网关）、千瓜、新红（路线 B）。没配凭证 → 卡上"未配置"，表单下方提示将返回样例数据。
3. 选蒲公英，窗口 30 天，关键词"护肤"，粉丝 1 万–50 万，健康只勾"优秀"，条数 50 → 运行。
4. 结果条显示"已加入队列 · 任务号"；任务表 3 秒内从 `排队中` → `进行中` → `完成`，状态下方"第 N 页 · 调用 M 次"，来源徽标带"样例"。
5. 讲：原始 JSON 原样落 `creator_raw`；转换层出 33 个指标，平台不给的是"—"；每次抓取一条快照。
6. 可选：把 `ingest_sources.quota` 改成 1 再跑一次，演示 `部分完成` + 续跑时间 + 重试按钮。

## 2. 运营端 → 审核发布 — 2 分钟

1. 概览页「待审核」数字 → 点进去就是「博主」列表的待审核标签。来源选「新红」，刚抓到的几位都在这里；搜索框输昵称能直接找到。
2. 点一位进详情：上面「发布时与最新」——还没发布，所以发布时一栏是「—」；下面趋势、资料、数据来源。
3. 点「平台原始信息」：每次抓到的原样内容按来源和时间排开，展开能看到平台给的全部字段。讲：原样留底，转换出错可以回查。
4. 顺手改一下显示名或内容方向，保存。
5. 点「通过并发布」→ 确认。状态变「已发布」，按钮变成「下架」。讲：发布那一刻的数字被冻结，选人端按这份数字筛选排序；之后再抓只更新「最新」一栏。
6. 可选：下架 → 进「已下架」标签 → 重新发布，选人端换成最新数字。

## 3. 选人端 → 博主池（7004）— 3 分钟

1. 登录 `selector@kcs.local`。池表默认方案：粉丝、阅读中位数、互动中位数、互动率、CPE…每格颜色是**同源同量级**分位，悬停看"同源同量级 N 人 · 蒲公英 · 腰部"。
2. 新建方案「护肤腰部性价比」：量级 = 腰部；健康 = 优秀；CPE ≤ 3；收藏/点赞 ≥ 0.8；排序 CPE 升序；高亮 CPE ≤ 2 绿、互动率 < 2% 琥珀；显示列加 图文一口价、搜索流量占比。保存。
3. 表格立刻收缩；方案 chip 出现在方案栏，刷新仍在。讲：这就是"评分"——用平台语言写条件，可保存、有版本，不算分。

## 4. 博主详情 — 1 分钟

点刚才发布的那位：「发布时与最新」两栏并排，之后再抓到的新数字和变化一眼看到。再点一个博主：身份条（量级、健康、来源、同源同量级 N 人）→ 趋势卡（粉丝 / 阅读 / 互动率 / CPE 四条折线，30 / 90 切换，展开快照表）→ 六组指标卡（分位条）→ 受众画像 → 数据来源卡（每个来源的 ID 与最后抓取时间；如果有归并会看到两行）。

## 5. 项目分派与导出 — 1 分钟

新建项目「9 月护肤投放」→ 从池里分派 3 人（含刚发布的那位）→ 项目页 KPI（人数、CPE 中位、互动率中位、健康分布）→「导出表格」。用 Excel 打开：中文表头、不乱码，数字是发布时的；切到 `en` / `ko` 再导出，表头跟着变。再演示「移出」：确认后这一行消失，重新导出也不再有。

## 6. 运维端（7003）— 30 秒

登录 `devops@kcs.local`：任务状态分布、流水线（每个来源今日调用 / 配额）、审计流（刚才的登录、发布、分派都在）。`失败` / `部分完成` 的任务可重试。侧栏里没有「账号」。

## 7. 运维端 → 账号（平台管理员）— 1 分钟

1. 换 `admin@kcs.local` 登录运维端，侧栏多出「账号」。列表里有每个人的角色、最近登录、状态。
2. 「新建账号」：邮箱 `demo-new@kcs.local`、初始密码、角色「运营录入」→ 新建。开一个无痕窗口用它登录宣传站，直接落到运营端。
3. 回账号页把它改成「选人」：提示「最多 10 秒后生效」。等 10 秒无痕窗口刷新运营端，变成无权限；顶栏切到选人端能进。
4. 「停用」→ 确认：无痕窗口里 10 秒内被退出，再登录被拒。讲：离职当天就能收回，不用改密码。
