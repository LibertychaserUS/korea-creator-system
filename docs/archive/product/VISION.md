# 产品愿景

> 项目标识：`korea-creator-system`（仓库、分支、工单前缀一律用这个）。
> 产品显示名：全球达人情报系统。
> 历史计划名：韩国品牌小红书达人 AI 筛选 Demo（V1 计划书，勿当仓库名）。
> 实现目标：**tinyship + forge + overlay** 绿地重建（三件套必用）。旧 Demo 已删除，只留 `docs/`。
> 栈硬约束：[`../pm/STACK.md`](../pm/STACK.md)。细则：[`TINYSHIP-REBUILD.md`](./TINYSHIP-REBUILD.md)。

## 一句话

把蒲公英（PGY）导出的小红书达人 Excel，变成韩国品牌可解释的推荐名单：清洗 → 去重 → **规则排序** → **风险复核** → **人工确认** → 导出。

V1 计划书原话口径（意译，非逐字照抄）：先做「可展示、可复核、可导出」的最小闭环；不登录账号、不抓网页、不识图识视频、不采多平台、不训练模型。

## 谁用

| 角色 | 要完成的工作 |
|------|----------------|
| 韩国品牌市场 / 投放 | 从一批 PGY Excel 里筛出可合作达人，并说清「为什么上榜、有什么风险、怎么试水」 |
| 内部复核员 | 对 Top50 做推荐 / 不推荐 / 待确认，留下备注；**不改分** |
| 演示讲解人 | 用中文 / 英文 / 韩文切换走完导入 → 榜单 → 详情 → 标注 → 导出（第一刀就要能切语言） |

## Jobs-to-be-done

1. **导入一次表，得到稳定名单**：同一 `creator_key` 不因重复行膨胀。
2. **规则给出可复现排序**：六维分 + 风险扣分 + 等级 + Top10 / Top50 / 全量。
3. **AI 只解释风险**：recommend / cautious / reject + 理由；**不改分、不改等级、不改排名**。
4. **人做最终决定**：标注进入导出，分数仍是规则分。
5. **带走文件**：带时间戳的 Excel / CSV，能给老师或客户。

## 成功指标（绿地 MVP 可验收）

- 能从固定路径读 0201（或 `data/input/current.xlsx`）并完成清洗去重。
- 能生成六维分、最终分、等级、Top10 / Top50 / 全量；每个达人能看到命中词与扣分原因。
- Top50 有 AI 或模板兜底说明；无 Key 时 Demo 仍能走完。
- 人工标注四态可用，导出文件含标注，**分数未因标注或 AI 改变**。
- 页面覆盖 V1 计划的六个轻量面：控制台、榜单、详情、规则（先只读）、人工复核、导出。
- 图表至少：Top10 条形、六维雷达、等级分布、关键词排行。
- 界面可在 `zh-CN` / `en` / `ko` 间切换；URL 能直接进某语；豁免原文四类不译。

## 原则（不变量）

- **规则排序**：排序只来自规则引擎。
- **风险复核**：AI 是解释层，不是排名层。
- **人工确认**：人确认合作，不回写分数。
- 不以复现 0202 样板排名为硬目标；以口径接近、结果可解释为验收。
