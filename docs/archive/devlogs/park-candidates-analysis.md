# 朴代表候选达人 AI 分析 - 开发日志

## 任务概述

朴代表提供了蒲公英导出的候选达人表（10人），需要复用现有 Demo 的评分和 AI 复核能力做一份候选达人分析报告。

## 分支

- `task/park-candidates-analysis`（从 `demo/v1-report` 创建）

## 约束

- 不自动登录蒲公英
- 不爬取小红书
- 不修改主评分流程（`services/scoring.py`）
- 不修改现有页面（`ui/dashboard-v2`）
- 不提交 API Key
- 不新增网页页面
- DeepSeek 不可用时使用 fallback 模板并标注

## 字段映射

| 蒲公英字段 | 内部字段 | 备注 |
|-----------|---------|------|
| 达人昵称 | 昵称 | 直接映射 |
| 小红书号 | 小红书号 | 直接映射 |
| 小红书主页 | 小红书主页URL | 直接映射 |
| 达人所属城市 | 地域 | 直接映射 |
| 粉丝数 | 粉丝数 | ×10000（蒲公英单位为万） |
| 达人标签 | 内容类目\|标签 + 抓取关键词 + 身份\|人设 | 三字段复用 |
| 阅读中位数（日常笔记·30天） | 阅读中位数_日常 | 直接映射 |
| 互动中位数（日常笔记·30天） | 互动中位数_日常 | 直接映射 |
| 互动率（日常笔记·30天） | 日常笔记ER | ×100 转百分比格式 |
| 图文笔记一口价 | 图文报价 | 直接映射 |
| 视频笔记一口价 | 视频报价 | 直接映射 |
| 过往合作品牌 | 过往合作品牌 | 额外保留 |
| 达人蒲公英后台链接 | 蒲公英链接 | 额外保留 |

缺失字段适配：
- 身份\|人设 → 用达人标签代替
- 互动中位数_合作 → 用互动中位数_日常代替
- 合作笔记ER → 用日常笔记ER代替
- 匹配笔记数 → 用近30天发布笔记数代替
- 全部报价 → 取图文/视频较大值

## 评分规则

完全复用现有六维评分权重：
- 分层筛选 25%（粉丝数分档）
- 关键词组合 15%（10个内容关键词命中百分位）
- 韩国品牌 25%（地域+韩国词+品牌词）
- 潜力合作 20%（粉丝+互动+笔记数）
- 表现 10%（阅读/互动中位数+ER）
- 性价比 5%（CPM 反向排名）

权重配置来源：`config/default_rules.json`、`config/keyword_groups.json`、`config/exclude_rules.json`

## AI 复核

- 调用 DeepSeek API（`deepseek-chat` 模型，temperature=0.3）
- 复用 `ai_recommendation.py` 的 prompt 结构
- 输出：AI结论（推荐/谨慎推荐/不优先推荐）、推荐理由、风险点、合作方向、是否建议优先联系
- API 不可用时使用 fallback 模板并标注 `[FALLBACK]`
