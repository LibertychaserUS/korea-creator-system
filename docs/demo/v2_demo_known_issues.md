# V2 Demo 已知问题与边界

## 当前已知边界
- 当前主要基于案例数据
- 暂不做自动爬取
- 暂不做自动联系
- 暂不做真实 ROI 预测
- 暂不做多平台自动同步
- AI 分析仅作辅助，最终以人工复核为准

## 当前技术边界
- 当前 V2 状态主要使用 JSON/cache 方式
- 后续如多人协作或部署，需要考虑数据库化
- 报告导出当前支持 Markdown 和 JSON
- Excel/PDF 可作为后续增强

## 当前演示风险
- 现有样例数据以案例数据为主，和真实线上业务仍有差距
- 如果直接在正式缓存上演示保存动作，可能写入新的复核、联系或报价记录
- 页面文案与部分历史字段仍带有阶段性实现痕迹，正式交付前建议再统一整理
- 当前导出报告更偏“结构化汇报草稿”，不是最终商业排版版本

## 后续建议
- 接入王家舜结构化导出数据
- 增强字段映射
- 增强报告模板
- 增加真实客户案例演示数据

## 建议答辩口径
- 强调本版本已经完成主链路闭环，而不是单点页面展示
- 强调系统定位为“辅助决策 + 人工复核 + 跟进沉淀”，不是全自动代替人
- 强调后续可继续向数据库化、模板化导出和真实业务接入扩展
