## 截图建议

- 统一使用中文界面，减少汇报切换成本。
- 如涉及真实案例名称，建议优先使用脱敏样例报告截图。
- 每张截图建议保留浏览器地址栏或页面标题，方便老师确认页面来源。
- 截图分辨率建议：至少 1366x768，优先 1920x1080。
- 截图前确保控制台无明显报错。
