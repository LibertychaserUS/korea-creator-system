# V2 Demo 汇报讲稿

## 1. 开场说明

当前系统定位：**韩国品牌达人数据统一管理与合作决策系统**。

核心价值：帮助韩国品牌在进入中国市场时，高效管理和筛选适合的内容创作者（达人/KOL），通过数据驱动的方式做出合作决策。

## 2. 项目背景

原始方向是构建完整的 AI Marketing Operating System，但经过可行性分析后，我们决定收敛范围：

- **不追求大而全**：不做完整的 AI Marketing OS
- **聚焦可验证闭环**：先做达人数据管理、分析、人工复核、联系跟进和报告导出的完整业务闭环
- **务实推进**：从案例数据入手，验证核心价值后再扩展

## 3. 当前 V2 已实现能力

| 能力模块 | 说明 |
|---------|------|
| 案例数据导入与管理 | 支持外部数据导入，批次管理，字段校验 |
| 达人筛选与分析 | 多维度筛选（平台、国家、等级、评分等） |
| AI 辅助分析 | DeepSeek 驱动的达人分析和决策建议 |
| 人工复核 | 标准化复核流程，支持保留、拒绝、待确认三种决策 |
| 复核原因标签 | 支持多标签选择，记录复核原因 |
| 规则复盘 | AI 与人工分歧统计，规则优化建议 |
| 联系 SOP | 联系状态跟踪，跟进时间管理 |
| 报价记录 | 平台参考价、询价报价、最终报价三级管理 |
| 批次报告导出 | 支持 Markdown 和 JSON 格式报告导出 |
| Demo 文档与样例报告 | 完整的演示材料和脱敏样例报告 |

## 4. 推荐演示流程

### 步骤 1：首页 / 控制台
- **操作**：打开首页，展示仪表盘概览
- **展示**：达人总数、Top50数量、最终分平均值、AI覆盖率、人工待确认数量等核心指标
- **业务意义**：一眼看到项目整体状态，快速把握数据规模和处理进度

### 步骤 2：达人列表
- **操作**：点击"达人库"导航，浏览达人列表
- **展示**：排名、昵称、平台、国家、等级、最终分、粉丝数、报价等字段；支持筛选和排序
- **业务意义**：全面了解达人数据，支持多维度筛选找到目标达人

### 步骤 3：达人详情抽屉
- **操作**：点击任意达人打开详情抽屉
- **展示**：达人基本信息、评分依据、AI分析、人工复核四个标签页
- **业务意义**：深入了解单个达人的完整信息，为决策提供依据

### 步骤 4：AI 分析
- **操作**：切换到"AI复核"标签页
- **展示**：AI决策结果、置信度、分析摘要、提示信息
- **业务意义**：借助 AI 快速获得初步判断，提高筛选效率

### 步骤 5：人工复核
- **操作**：切换到"人工复核"标签页，选择决策（保留/拒绝/待确认）
- **展示**：决策按钮、备注输入、保存按钮
- **业务意义**：人工最终确认，确保决策质量

### 步骤 6：复核原因标签
- **操作**：在人工复核页选择原因标签
- **展示**：多个可多选的标签按钮（如"粉丝质量低"、"内容不匹配"等）
- **业务意义**：标准化记录复核原因，为后续规则优化提供数据支撑

### 步骤 7：规则复盘页
- **操作**：点击"规则设置"导航
- **展示**：AI与人工分歧统计、分歧类型排行、规则优化建议
- **业务意义**：发现评分规则的不足，持续优化筛选标准

### 步骤 8：联系与报价
- **操作**：在达人详情抽屉中切换到"联系与报价"标签页
- **展示**：联系状态、联系渠道、负责人、报价信息（平台参考价、询价报价、最终报价）
- **业务意义**：跟踪与达人的沟通进度，记录报价信息

### 步骤 9：联系跟进看板
- **操作**：点击"邮件触达"导航
- **展示**：联系状态分布统计、候选达人列表、报价汇总
- **业务意义**：全局管理联系进度，把握合作节奏

### 步骤 10：报告导出页
- **操作**：点击"数据与导出"导航
- **展示**：报告生成、导出按钮（Markdown/JSON）、导出文件列表
- **业务意义**：一键生成完整报告，便于团队分享和归档

### 步骤 11：样例报告
- **操作**：展示已导出的样例报告
- **展示**：报告包含的内容结构（摘要、批次信息、分析结果、人工复核统计、联系汇总等）
- **业务意义**：展示系统的最终交付物，体现数据价值

## 5. 当前版本边界

明确说明以下功能**暂不实现**：

- ❌ 暂不做自动爬取：不自动从平台采集达人数据
- ❌ 暂不做自动登录：不实现平台自动登录功能
- ❌ 暂不做自动私信：不实现自动发送私信/邮件
- ❌ 暂不做自动群发：不实现批量群发功能
- ❌ 暂不做真实 ROI 预测：不做销售归因和 ROI 计算
- ⚠️ AI 分析只是辅助：AI 输出仅供参考，最终以人工复核为准
