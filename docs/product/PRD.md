## V1 计划要的闭环（必须进 MVP）

计划书「三、V1 范围边界 / 十一、验收标准」摘要：

1. 固定路径读 0201，回退 `data/input/current.xlsx`。
2. 清洗、数值标准化、标签去噪、按 `userId > 小红书号 > 主页 URL` 去重。
3. 六维规则分、最终分、等级、Top10 / Top50 / 全量。
4. 仅 Top50 调 DeepSeek；无 Key / 失败用模板兜底。
5. 人工：推荐 / 不推荐 / 待确认 / 已复核；**不直接改最终分**。
6. 导出带时间戳的 Excel / CSV（Top10、Top50、全量、含标注）。
7. 六个轻量面：控制台、榜单、详情、规则配置、人工复核、导出。
8. 图表：Top10 条形、六维雷达、等级统计、关键词排行。
9. **中英韩三语**：`zh-CN` / `en` / `ko`。计划书曾写「V1 中文、V1.1 语言包」——**作废为 Later**。绿地第一刀就要语言切换；六个面交付时三语都在。

计划书阶段 1 曾写「FastAPI + SQLite 骨架」。**该栈选择作废**。存储与框架以 `TINYSHIP-REBUILD.md` 为准；产品闭环不变。

## 评分口径（产品约束，实现可校准）

计划书建议等级：S≥85 / A 75–84.99 / B 65–74.99 / C<65。旧引擎因百分位分布改为 S≥80 / A≥65 / B≥50 / C≥35 / D<35（见 `docs/03_评分规则说明.md`）。绿地重建时：

- 六维名称与权重先沿用计划书：分层 25 / 关键词组合 15 / 韩国品牌 25 / 潜力 20 / 表现 10 / 性价比 5，风险 0～-10。
- 阈值可按数据再校准，但必须写在规则配置里，且 **AI / 人工不得改分**。
- 0202 只作字段与口径参考，不要求复现排名。

细则指针：改权重或扣分前读 `docs/03_评分规则说明.md` 与 [`DOMAIN.md`](./DOMAIN.md)。

## 语言（硬约束，不是 Later）

- 界面语言：`zh-CN`、`en`、`ko`。默认 `zh-CN`。
- 第一刀（hello-world / 宿主）就必须能切换，禁止中文-only 脚手架对外演示。
- 实现走 TinyShip 真实模式：`libs/i18n` + Nuxt `@nuxtjs/i18n` 前缀路由 + cookie `NEXT_LOCALE`。细则 [`TINYSHIP-REBUILD.md`](./TINYSHIP-REBUILD.md) §5.1。
- 旧 Demo 的 `?lang=` + `localStorage` + 扁平 `t()` **只保留产品行为**（URL 进某语、刷新保持、`t()` 渲染 chrome）。不要搬 archive 实现。
- 豁免原文（不翻译）：达人昵称、小红书号、原始抓取关键词、手写备注。
- 切语言不重跑排序 / 不改 `score` / `grade` / `rank`。AI 正文是展示层翻译，等风险复核票再做，不是第一刀范围。

## 非目标（本轮 / 本仓库下一阶段）

- 不把仓库根当作还活着 `app/`。旧代码只在 `archive/`；不在那里做 Stage 8B 或继续堆 V2。
- 不搬迁、不归档 `docs/`。
- 不自动登录蒲公英 / 小红书；不抓主页、笔记、图、视频。
- 不多平台采集（B 站 / TikTok / IG / YT）。
- 不训练模型；不承诺识别视频里是否出现韩国品牌。
- 不自动发邮件 / 私信 / 群发。
- 不做三角色平台（Admin / Brand / Influencer）、活动报名、合同结算——那是后续 IMOK / V3 方向，不是本 MVP。
- 不引入 Harness.io（CI/CD 产品）。本仓库说的 harness = 代理工作流：`AGENTS.md`、superpowers、writing-for-agents、writing-plans。

## 验收（绿地 MVP）

完成当且仅当下列全部为真（在 **tinyship 新应用** 上，不是 `archive/` 里的旧进程）：

- [ ] 读入 0201 或 `data/input/current.xlsx`，去重后人数可解释（旧批次参考 4958→1725，新跑分允许复核）。
- [ ] 每条达人有六维分、最终分、等级、排名、命中词、风险原因。
- [ ] Top50 每条有 AI 或 fallback 文本；`score` / `grade` / `rank` 在 AI 调用前后字节级一致（或数值相等）。
- [ ] 人工改标注后再读详情与导出：标注变了，分数不变。
- [ ] 导出文件带时间戳，含榜单与标注。
- [ ] 六个轻量面可点通；无 Key 也能演示。
- [ ] 顶栏可切 `zh-CN` / `en` / `ko`；`/zh-CN` `/en` `/ko` 与 `?lang=` 都能进对应语言；六个面 chrome 三语齐全；豁免原文四类未译。
- [ ] 未改 `archive/` 冻结代码（墓碑由归档代理维护）；未动 `docs/00_*`–`10_*` 当新施工图。

## 旧代码怎么用

旧 Demo 只在 `archive/`。对照时读那里的入口 / 规则 / AI，**不要假设仓库根还有 `app/`**。

| 可借 | 不可做 |
|------|--------|
| 字段名、去重键、六维权重、冲突口径、i18n 豁免（昵称 / 小红书号 / 原始关键词 / 手写备注） | 把 archive 里的旧页「补完」当交付 |
| V2 联系 / 规则复盘 / 批次导入的 **产品意图**（中期票） | 继续扩 archive 内 `/api/v2/*` 当主线 |
| `docs/` 编号文档里的真实口径与已知坑 | 把 `v8a-dashboard` 写成「当前实现目标」 |
| archive 墓碑上的冻结说明 | 把 `docs/` 搬进 archive |
