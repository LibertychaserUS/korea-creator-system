## 分工作区说明

### 共用

**AUTH-LOGIN**  
空：无。错：账号不存在 / 密码错。数据：不读 Creator。登录后按角色进 `/select`、`/ops`、`/dev` 或 `/ingest`。

**AUTH-DENIED**  
空：零 Creator 行、零 Job 摘要。主按钮回自己的工作区。

---

### 前台 · 选人 ` /select `

目的：已经整理好的库，3 步分到项目。  
禁止：原始入库痕迹、待补表单、Job 失败栈、改分类/报价、录入入口。

**SEL-PROJECT-LIST**  
空：0 项目，主按钮「新建项目」。错：加载失败可重试。默认序：最近更新↓。

**SEL-PROJECT-NEW**  
空：无。错：名称为空禁用提交。重名允许。

**SEL-PROJECT**  
空：0 人，主按钮「从库选人」。错：移出失败保留行。列：显示名、分类、粉丝、报价、分配状态、移出。已不在库角标。

**SEL-LIBRARY**  
空：池 0 人（运营尚未发布）vs 筛后 0 人（清空筛选）必须能区分文案。错：加载失败。默认筛/序见 PRD §6.2。列禁止：源任务 id、缺字段、draft、失败原因。

**SEL-CREATOR**  
空：未发布 id → 404（即使后台存在）。错：分配失败保留「加入」可用。

**SEL-ASSIGN**  
空：未勾选禁用确认。错：部分失败列出谁没进去，已成功的不回滚（提示去项目里移出）。

筛排序字段以 PRD §6 为准，本屏不另发明一列。

---

### 后台 · 运营录入 ` /ops `

目的：手工录入、校对自动结果、分类、发布。  
数据可含未发布与源任务；这些 API 不得给选人 token。

**OPS-HOME**  
空：库存 0，主按钮「录入第一人」；次按钮「去看入库任务」。错：最近发布失败摘要 + 链到该人详情。

**OPS-CREATOR-LIST**  
空：见 PRD §6.2。必须有状态列与源任务列（无则写「手工」）。主按钮「录入达人」。

**OPS-CREATOR-NEW / EDIT**  
空：未填禁用保存。错：校验贴在字段上。EDIT 在标签与履历冲突时显示角标。无「改分配」。

**OPS-CREATOR-DETAIL**  
空：未知 id → 404。主按钮：`ready`/齐备时「发布」；`released` 时「撤回」。确认层必须有。

**OPS-REVIEW**  
空：待校对 0。错：通过失败保留在队列。主路径来自 Job 成功后的抽检/全量待校对。

**OPS-CATEGORY**  
空：无（内置至少 2 条）。错：停用内置 `collaborated` / `never_collaborated` 应拒绝。可改显示名。

---

### 后台 · 开发运维监测 ` /dev `

目的：任务、失败、健康、管道。  
禁止：达人筛选工作台、推荐、分配、改报价。

**DEV-HEALTH**  
空：服务起来但从未有 Job。错：健康红 + 链 `DEV-JOBS`。

**DEV-JOBS**  
空：无任务。错：行标红。M1 可在本页展开一行代替独立路由，但仍要有 `DEV-JOB-DETAIL` 出图。

**DEV-JOB-DETAIL**  
空：未知 id → 404。错：摘要必在；无密钥。重试仅运维，进行中禁用连点。

---

### 后台 · 自动拉数 ` /ingest `

目的：配置并观察入库任务。  
禁止：临时 URL、站点突破步骤、选人表格。

**ING-SOURCE-LIST**  
空：0 源，「尚无可用来源」（找运维登记）。未启用源可见但不可选为开跑目标。

**ING-JOB-LIST**  
空：0 任务，主按钮「配置任务」。默认序：创建时间↓。

**ING-JOB-NEW**  
空：无启用源则禁用提交。错：超配额预检失败。控件：源、once/周期、抽检比例、确认。

**ING-JOB-DETAIL**  
空：无。进行中：心跳。成功：写入/去重计数 + 「抽检」。失败：摘要 + 重试/新开。未开跑：可取消。

**ING-SAMPLE**  
空：写入 0 或样本 0，明示原因。主按钮「去校对」进 `OPS-REVIEW`（可带 job 过滤）。

## 一页一做时的领取规则（出图之后）

- 一次只领 **一个 id**（例外：AUTH-LOGIN + AUTH-DENIED 可同领）。
- 对照该 id 的 mockup + 本表 widgets + PRD §12 验收。
- 先写失败测试再写页。测：角色进错工作区 403；未发布/黑名单前台 404 或空；Job 重试不复制 `creator_key`。
- 合入前 `python3 -m forge check`（旁仓 AIOps）。
- 不要顺手做相邻未领取屏。
- 不要把 `docs/00_*` 或 archive 的页面当验收标准。
