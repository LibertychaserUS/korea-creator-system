# 项目总览

## 项目定位
- 项目名称：全球达人情报系统
- 目标：基于小红书蒲公英原始数据，完成达人清洗、评分、AI风险复核、人工标注、导出与演示闭环。
- 当前定位：面向韩国品牌小红书达人筛选 Demo，强调“规则评分负责排序，AI负责风险复核，人工负责最终确认”。

## 当前页面结构
- 概览：核心指标、Top10 分数图、等级分布、关键词排行、地区分布、AI状态概览、最近人工复核。
- 达人库：Top10 / Top50 / 全量切换，筛选、搜索、分页、排序、导出、详情抽屉。
- AI复核：AI覆盖率、success/fallback/失败统计、决策分布、待复核列表、批量生成入口。
- 人工复核：本轮保留导航与统一空状态，下一阶段完善独立页。
- 邮件触达：本轮保留导航与统一空状态，下一阶段完善。
- 数据与导出：本轮保留导航与统一空状态，下载能力仍从达人库可用。
- 规则设置：本轮保留导航与统一空状态，下一阶段完善。

## 技术栈
- 后端：FastAPI + Uvicorn
- 前端：原生 HTML / CSS / JavaScript
- 图表：ECharts
- 数据处理：pandas + openpyxl
- AI：DeepSeek API + 本地缓存 + fallback
- 数据存储：CSV / Excel / JSON（V1 轻量存储）

## 数据闭环
1. 读取原始 Excel 数据。
2. 进行清洗、去重、规则评分。
3. 生成 Top10 / Top50 / 全量结果。
4. 对 Top50 读取 AI复核结果或触发生成。
5. 人工进行推荐 / 不推荐 / 待确认 / 已复核标注。
6. 输出 Excel / CSV，供演示与交付使用。

## V1 取舍说明
- 不自动登录蒲公英。
- 不抓取小红书主页。
- 不做图片/视频识别。
- 不做多平台采集。
- 不训练模型。
- 全量达人仍以规则评分为主。
- AI 不修改评分、等级、排名。
- V1 继续使用 CSV / JSON，不引入数据库依赖；SQLite 作为 V2 方向保留。
