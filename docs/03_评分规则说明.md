# 评分规则说明

## 评分引擎版本
- `v5-stage5` / 2026-06-17

## 六维评分体系

### 1. 分层筛选 (25%)
按粉丝数量级分为五档：
| 粉丝数 | 得分 |
|--------|------|
| >= 1,000,000 | 100 |
| >= 300,000   | 90  |
| >= 150,000   | 80  |
| >= 100,000   | 65  |
| < 100,000    | 50  |

> 当前数据集粉丝数范围为 50k ~ 4.49M，所有达人至少获得 50 分。

### 2. 关键词组合 (15%)
- 将 `内容类目|标签` + `身份|人设` + `抓取关键词` 合并为统一文本。
- 统计 `config/keyword_groups.json` 中 `content_keywords`（10个：时尚、穿搭、美妆、vlog、生活方式、开箱、旅行、探店等）的命中数。
- 命中数做百分位归一化，映射到 0-100 分。
- 同时记录 `hit_content_keywords` 字段列出具体命中的关键词。

### 3. 韩国品牌 (25%)
三重信号叠加（满分 100）：
- **地域信号（40分）**：`地域` 字段含"韩国"直接给 40 分。
- **韩国关键词（30分）**：对全文本匹配 `korea_keywords`（11个：首尔、圣水洞、明洞、釜山、济州等），命中数百分位归一化后 × 0.30。
- **品牌关键词（30分）**：对全文本匹配 `brand_keywords`（9个：Rockfish、Martin Kim、Marithe、EMIS 等），命中数百分位归一化后 × 0.30。
- 无匹配时给基础 10 分保底。
- 同时记录 `hit_korea_keywords` 和 `hit_brand_keywords` 字段。

### 4. 潜力合作 (20%)
三项指标百分位加权合成：
- 粉丝数 × 0.40
- 互动中位数_合作 × 0.35
- 匹配笔记数 × 0.25

### 5. 表现 (10%)
四项指标等权百分位合成：
- 阅读中位数_日常 × 0.25
- 互动中位数_日常 × 0.25
- 合作笔记ER × 0.25（解析 "3.48%" 格式）
- 日常笔记ER × 0.25

### 6. 性价比 (5%)
- CPM = 全部报价 / 粉丝数 × 1000
- CPM 越低越好，取反向百分位（1 - rank_pct）× 100
- 无报价者默认 30 分

## 风险扣分 (0 ~ -10)
| 扣分项 | 条件 | 扣分 |
|--------|------|------|
| 身份画像缺失 | 身份\|人设 为空 | -2 |
| 内容标签缺失 | 内容类目\|标签 为空 | -2 |
| 合作互动为零 | 互动中位数_合作 == 0 | -2 |
| 合作ER过低 | 合作笔记ER < 1% | -2 |
| CPM极端高 | CPM 处于全量前 5% | -2 |
| 排除类型匹配 | 命中 exclude_keywords 关键词 | -3 |

> 扣分原因记录在 `risk_reasons` 字段，分号分隔。

## 排除规则
匹配 `config/exclude_rules.json` 中的 `exclude_keywords`（"纯KPOP追星""纯美食探店""纯旅游攻略"）：
- 在 `内容类目|标签` + `身份|人设` 中匹配
- 命中者标记 `exclude_flag = True`
- 追加 -3 分风险扣分
- Web 页面支持按排除标记筛选

## 最终分计算
```
最终分 = layered_match × 0.25
      + keyword_combo × 0.15
      + korea_brand × 0.25
      + cooperation_potential × 0.20
      + performance × 0.10
      + cost_effectiveness × 0.05
      + risk_deduction
```
结果 clip 到 [0, 100]。

## 推荐等级（统一标准）
| 等级 | 阈值 | 短标签 | 含义 |
|------|------|--------|------|
| S级(强烈推荐) | >= 80 | S | 顶级匹配 |
| A级(推荐)     | >= 65 | A | 优质匹配 |
| B级(可考虑)   | >= 50 | B | 中等匹配 |
| C级(观望)     | >= 35 | C | 一般匹配 |
| D级(不推荐)   | < 35  | D | 不匹配 |

### 与计划书阈值差异说明
计划书建议 S≥85 / A=75-84.99 / B=65-74.99 / C<65，实际代码采用 S≥80 / A≥65 / B≥50 / C≥35 / D<35。

差异原因：
1. **数据驱动校准**：当前 1725 人最高分仅 75.8，无达人达到 85 分——按计划书阈值将导致 0 人 S 级，仅 4 人 A 级，等级分布严重失衡。
2. **百分位归一化效果**：六维评分采用百分位归一化而非绝对分数，均值天然分布在 50 分附近；因此各等级需以 50 分（而非 75 分）作为 A/B 分界线。
3. **同一批数据验证**：计划书也明确"不以复现样板排名为硬目标，以评分口径接近、结果可解释为验收标准"。当前 50-65 分区间（B 级）含 452 人，85-95 百分位段，与计划书 B 级意图（前 30%）一致。
4. **可调性**：阈值存储在 `services/scoring.py` 的 `GRADE_THRESHOLDS` 列表中，随数据质量提升可一键调高各档位。

## 评分解释字段
| 字段 | 说明 |
|------|------|
| `hit_content_keywords` | 命中的内容关键词，逗号分隔 |
| `hit_korea_keywords` | 命中的韩国关键词，逗号分隔 |
| `hit_brand_keywords` | 命中的品牌关键词，逗号分隔 |
| `risk_reasons` | 风险扣分原因，分号分隔 |
| `exclude_flag` | 是否命中排除规则 |
| `grade_short` | 等级短标签 S/A/B/C/D |

## 配置文件
- `config/default_rules.json` — 权重与风险上限
- `config/keyword_groups.json` — 关键词分组（内容/韩国/品牌）
- `config/exclude_rules.json` — 排除规则（已接入代码）
